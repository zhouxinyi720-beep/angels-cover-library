# angels-cover-library

微信读书纪实垂类封面参考图库。收录541本纪实与社科类电子书封面，支持按内容主题与视觉风格检索，并可一键反推结构化设计提示词，供AI生图直接使用。

## 功能

- 按内容检索：社科、纪实文学、纪实故事3个大类，下设15个细分小类与13个内容主题，一本书可归入多个主题。
- 按视觉检索：插画手绘、摄影纪实、极简留白、复古质感、高饱和波普、暗调极简、拼贴艺术、文字排版，共8种视觉风格，每本书归入一种核心视觉分类。
- 反推设计提示词：点开封面生成配色方案、排版方案、设计风格与构图方案，可一键复制。
- 支持上传新封面、打标签、修改视觉分类，数据保存在浏览器本地。

## 目录说明

- `index.html` 页面入口。
- `assets/` 构建后的脚本与样式。
- `covers/` 541张封面图。
- 其余为页面背景素材。

## 部署

已按相对路径构建，可直接作为静态站点部署。上传到 GitHub 仓库后，在 Settings → Pages 中选择分支与根目录即可访问。

访问地址为 `https://<用户名>.github.io/angels-cover-library/`。

## 说明

当前反推采用本地取色与规则推断，排版与风格建议仍需人工判断。后续计划接入视觉大模型，并支持团队共享。
